=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


host
====




 - Datentyp: **ip**


kwltype
=======




 - Datentyp: **str**
 - Standardwert: **comfoair350**

 - Mögliche Werte:

   - **comfoair350**
   - **comfoair500**


port
====




 - Datentyp: **int**


serialport
==========




 - Datentyp: **str**

=============




 - Datentyp: **str**


comfoair_read_afterwrite
========================

comfoair_read_cycle

 - Datentyp: **num**


comfoair_send

comfoair_trigger

 - Datentyp: **num**
