Anforderungen
=============

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **snmp** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


cycle
=====




 - Datentyp: **int**
 - Standardwert: **300**


snmp_community
==============




 - Datentyp: **str**


snmp_host
=========




 - Datentyp: **str**


snmp_port
=========




 - Datentyp: **int**
 - Standardwert: **161**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


snmp_oid
========




 - Datentyp: **str**


snmp_prop
=========




 - Datentyp: **str**

 - Mögliche Werte:

   - **value**
   - **string**
   - **hex-string**
   - **mac-adress**
   - **ip-adress**
   - **error-state**
