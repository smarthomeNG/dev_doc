Anforderungen
=============

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **mlgw** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


host
====




 - Datentyp: **ip**
 - Standardwert: **mlgw.local**


log_mlgwtelegrams
=================




 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**
 - Maximalwert: **4**

mlns
====




 - Datentyp: **str**


password
========




 - Datentyp: **str**
 - Standardwert: **mlgw**


port
====




 - Datentyp: **int**
 - Standardwert: **9000**

 - Minimalwert: **0**

rooms
=====




 - Datentyp: **str**


username
========




 - Datentyp: **str**
 - Standardwert: **mlgw**


==============

Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


mlgw_cmd
========




 - Datentyp: **str**
 - Standardwert: **[]**


mlgw_listen
===========




 - Datentyp: **str**
 - Standardwert: **[]**


mlgw_mln
========




 - Datentyp: **str**
 - Standardwert: **[]**


mlgw_room
=========




 - Datentyp: **str**
 - Standardwert: **[]**


mlgw_send
=========




 - Datentyp: **str**
 - Standardwert: **[]**
