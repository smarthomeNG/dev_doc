Beschreibung
============

Plugin zur Datenabfrage des BSB-LAN-Adapters


Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.8**
 - Minimum Python Version: **3.7**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **bsblan** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


bsblan_ip
=========


IP Adresse des BSB-Lan Adapters

 - Datentyp: **str**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


bsb_lan
=======


Parameternummer des BSB-LAN-Adapters, die diesem Item zugeordnet wird. Eine vollständige Liste der unterstützten Parameternummern liefert die Web-Oberfläche des BSB-LAN-Adapters unter http://<ip>/K. Je nach Parameter liest oder schreibt das Plugin darüber den Wert des Items; ein schreibgeschützter Parameter wird bei einem Schreibversuch mit einer Fehlermeldung im Log quittiert.

 - Datentyp: **num**
