=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


cycle
=====




 - Datentyp: **num**
 - Standardwert: **5**


host
====




 - Datentyp: **ipv4**


tsap_client
===========




 - Datentyp: **num**
 - Standardwert: **256**


tsap_server
===========




 - Datentyp: **num**
 - Standardwert: **512**


version
=======




 - Datentyp: **str**
 - Standardwert: **0BA7**

 - Mögliche Werte:

   - **0BA7**
   - **0BA8**
