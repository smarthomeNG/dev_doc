Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


cycle
=====




 - Datentyp: **int**
 - Standardwert: **300**


fast_cycle
==========




 - Datentyp: **int**
 - Standardwert: **10**


host
====




 - Datentyp: **str**
 - Standardwert: **dreambox**


password
========




 - Datentyp: **str**


port
====




 - Datentyp: **int**
 - Standardwert: **80**


ssl
===




 - Datentyp: **bool**
 - Standardwert: **True**


username
========




 - Datentyp: **str**


verify
======




 - Datentyp: **bool**
 - Standardwert: **False**
