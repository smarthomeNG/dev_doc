=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


cycle
=====


Das Abfrage-Intervall für die gegebene Datenquelle in Sekunden

 - Datentyp: **int**
 - Standardwert: **30**

 - Minimalwert: **0**

jq_syntax
=========


Wenn true (Standard), werden jsonread_filter-Ausdrücke im auch bisher verwendeten jq-Dialekt interpretiert (führender Punkt, ["N"]-Array-Index, select()-Syntax). Wenn false, werden Ausdrücke direkt als native JMESPath-Syntax übergeben — für Nutzer,  die zu JMESPath migrieren oder neu einsteigen und von einer vollständig getesteten Bibliothek profitieren wollen. 

 - Datentyp: **bool**
 - Standardwert: **True**


url
===


URL der JSON Datenquelle. Aktuell unterstützt werden Webprotokolle https:// und http:// sowie ein Dateiadapter file:/// (benötigt wirklich 3 Schrägstriche) 

 - Datentyp: **str**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


jsonread_filter
===============


JQ Pfad, um innerhalb eines JSON-Datensatzes einen Wert auszuwählen. Dieser Wert wird dem Item dann zugewiesen.

 - Datentyp: **str**
