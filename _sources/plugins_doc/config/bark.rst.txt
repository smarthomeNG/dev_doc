Beschreibung
============

Push-Benachrichtigungen über einen Bark-Server


Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.10**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **bark** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


device_key
==========


Geräteschlüssel, den die Bark-App anzeigt

 - Datentyp: **str**


pause_item
==========


Item, um die Ausführung des Plugins zu steuern

 - Datentyp: **str**


server_url
==========


Basis-URL des Bark-Servers ohne "/push", z.B. "http://192.168.1.10:8080"

 - Datentyp: **str**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


bark_text
=========


Text der Benachrichtigung. "VAL" wird durch den Item-Wert ersetzt.

 - Datentyp: **str**


bark_title
==========


Überschrift der Benachrichtigung. "VAL" wird durch den Item-Wert ersetzt.

 - Datentyp: **str**


bark_url
========


URL, die beim Antippen geöffnet wird. "VAL" wird durch den Item-Wert ersetzt.

 - Datentyp: **str**


bark_values
===========


Liste von "Wert: Text"-Paaren. Entspricht der Item-Wert einem Wert, wird dessen Text statt "bark_text" gesendet.

 - Datentyp: **list(dict)**

================
Plugin Functions
================


Das Plugin verfügt über folgende öffentliche Funktionen, die z.B. in Logiken aufgerufen werden können.


notify(body, title= 'None*', url= 'None*')
==========================================


Versendet eine Push-Benachrichtigung. Liefert True, wenn der Server sie angenommen hat.

 - Ergebnistyp der Funktion: **bool**

**Parameter:**

**body**
    Text der Benachrichtigung

    - Datentyp: **str**

**title**
    Überschrift über dem Text

    - Datentyp: **str**
    - Standardwert: **None***

**url**
    URL, die beim Antippen der Benachrichtigung geöffnet wird

    - Datentyp: **str**
    - Standardwert: **None***
