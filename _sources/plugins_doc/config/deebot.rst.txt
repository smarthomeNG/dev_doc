Beschreibung
============

Plugin für Ecovacs Deebot Saugroboter über die Ecovacs Cloud


Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.12.2.2**
 - Minimum Python Version: **3.14**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **deebot** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


account
=======


Ecovacs Konto Login (E-Mail-Adresse)

 - Datentyp: **str**


country
=======


Land des Ecovacs Kontos als zweistelliger ISO-Code (z.B. DE). Bestimmt den Cloud-Server

 - Datentyp: **str**


device
======


Name (Nickname), Gerätename oder ID des Saugroboters. Leer: erster Roboter des Kontos

 - Datentyp: **str**


enable_map
==========


Karte als SVG erzeugen (Item map_svg und Web Interface)

 - Datentyp: **bool**
 - Standardwert: **True**


map_css
=======


CSS-Regeln, die an das Stylesheet der Karte angehängt werden. Standard: durchsichtiger Boden (.u), damit die Karte zum Theme passt. Leer lässt die Farben des Roboters unverändert

 - Datentyp: **str**
 - Standardwert: **.u{fill: transparent}**


map_trace
=========


Reinigungsspur in der Karte zeigen. Ohne Spur wird die Karte deutlich kleiner

 - Datentyp: **bool**
 - Standardwert: **True**


password
========


Ecovacs Konto Passwort

 - Datentyp: **str**


room_names
==========


Eigene Raumnamen, überschreiben die Namen des Roboters. Liste von Einträgen {room: 3, name: Küche}; mit map: <Kartenname oder Karten-ID> gilt ein Eintrag nur für diese Karte, sonst für alle. Namen und IDs der Karten liefert das Item maps

 - Datentyp: **list**
 - Standardwert: **[]**


room_preselect
==============


Im smartVISU Widget vorausgewählte Räume. Liste von Einträgen {room: 3}; map: <Kartenname oder Karten-ID> beschränkt einen Eintrag auf eine Karte, select: false hebt eine allgemeine Vorauswahl auf

 - Datentyp: **list**
 - Standardwert: **[]**

============
Item-Structs
============


Das Plugin stellt die folgenden Item-Structs zur Verfügung. Diese Informationen sind aus der `plugin.yaml` entnommen und möglicherweise nicht vollständig.

===

Alle Items des Saugroboters

     - :dir:`folder` **all** (`foo`, Alle Items des Saugroboters)

         - :dir:`file` **statistics** (`foo`, ---)
         - :dir:`file` **lifespan** (`foo`, ---)
         - :dir:`file` **map** (`foo`, ---)


control
=======

Steuerung

.. treeview::
     - :dir:`folder` **control** (`foo`, Steuerung)
         - :dir:`file` **cmd_start** (`bool`, auf True setzen, um die Reinigung zu starten (pausiert: fortsetzen); setzt sich selbst zurück)
         - :dir:`file` **cmd_pause** (`bool`, auf True setzen, um die Reinigung zu pausieren; setzt sich selbst zurück)
         - :dir:`file` **cmd_resume** (`bool`, auf True setzen, um die Reinigung fortzusetzen; setzt sich selbst zurück)
         - :dir:`file` **cmd_stop** (`bool`, auf True setzen, um die Reinigung zu beenden; setzt sich selbst zurück)
         - :dir:`file` **cmd_dock** (`bool`, auf True setzen, um zur Ladestation zurückzufahren; setzt sich selbst zurück)

         - :dir:`file` **cmd_empty_dustbin** (`bool`, auf True setzen, um den Staubbehälter in der Station zu entleeren; setzt sich selbst zurück)
         - :dir:`file` **cmd_clean_rooms** (`list`, Liste von Raum-IDs (siehe rooms) schreiben, um diese Räume einmal zu reinigen; setzt sich selbst zurück)

map
===

Position und Karte

.. treeview::
     - :dir:`folder` **map** (`foo`, Position und Karte)
         - :dir:`file` **position** (`dict`, Position des Roboters auf der Karte als {x, y, angle})
         - :dir:`file` **charger_position** (`dict`, Position der Ladestation auf der Karte als {x, y, angle})

==========

Statistik

     - :dir:`folder` **statistics** (`foo`, Statistik)
         - :dir:`file` **clean_area** (`num`, Fläche der aktuellen/letzten Reinigung in m²)

         - :dir:`file` **total_cleanings** (`num`, Anzahl aller Reinigungen)


status
======

Status des Saugroboters

.. treeview::
     - :dir:`folder` **status** (`foo`, Status des Saugroboters)
         - :dir:`file` **state** (`str`, Zustand: idle, cleaning, returning, docked, error oder paused)
         - :dir:`file` **active** (`bool`, true, solange der Roboter fährt (cleaning oder returning))
         - :dir:`file` **battery** (`num`, Akkustand in %)
         - :dir:`file` **available** (`bool`, true, wenn der Roboter über die Ecovacs Cloud erreichbar ist)
         - :dir:`file` **error_code** (`num`, Fehlercode des Roboters, 0 = kein Fehler)
         - :dir:`file` **error_text** (`str`, Fehlerbeschreibung zu error_code)
         - :dir:`file` **station_state** (`str`, Zustand der Station: idle, emptying_dustbin, washing_mop oder drying_mop)

================
Plugin Functions
================


Das Plugin verfügt über folgende öffentliche Funktionen, die z.B. in Logiken aufgerufen werden können.


clean_rooms(rooms, count=1)
===========================


Reinigt die angegebenen Räume. Die Raum-IDs liefert das Item mit deebot: rooms

 - Ergebnistyp der Funktion: **bool**

**Parameter:**

**rooms**
    Liste der Raum-IDs

    - Datentyp: **list**

**count**
    Anzahl der Reinigungsdurchgänge

    - Datentyp: **int**
    - Standardwert: **1**
