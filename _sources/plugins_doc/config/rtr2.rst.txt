Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.8.0**
 - Minimum Python Version: **3.6**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **rtr2** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


comfort_temp
============




 - Datentyp: **num**
 - Standardwert: **21.0**


default_Kd
==========




 - Datentyp: **num**


default_Ki
==========




 - Datentyp: **num**
 - Standardwert: **120**


default_Kp
==========




 - Datentyp: **num**
 - Standardwert: **4**


fixed_reduction
===============




 - Datentyp: **bool**
 - Standardwert: **True**


frost_temp
==========




 - Datentyp: **num**
 - Standardwert: **7.0**


hvac_mode
=========




 - Datentyp: **int**
 - Standardwert: **2**

 - Minimalwert: **1**
 - Maximalwert: **4**

max_output
==========




 - Datentyp: **num**
 - Standardwert: **100**

 - Minimalwert: **20**
 - Maximalwert: **100**

min_output
==========




 - Datentyp: **num**
 - Standardwert: **0**

 - Minimalwert: **0**
 - Maximalwert: **25**

night_reduction
===============




 - Datentyp: **num**
 - Standardwert: **3.0**


standby_reduction
=================




 - Datentyp: **num**
 - Standardwert: **1.5**


valve_protect
=============




 - Datentyp: **bool**
 - Standardwert: **True**

   - **setting_night_reduction**
   - **setting_standby_reduction**
   - **setting_fixed_reduction**
   - **setting_temp_frost**
   - **setting_min_output**
   - **setting_max_output**

rtr2_settings
