Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.8**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **webpush** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


grouplist
=========




 - Datentyp: **list**
 - Standardwert: **['alarm', 'info']**


varpath
=======




 - Datentyp: **str**
 - Standardwert: **/usr/local/smarthome/var**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


webpush_communication
=====================




 - Datentyp: **str**

 - Mögliche Werte:

   - **fromclient**


webpush_config
==============




 - Datentyp: **str**

 - Mögliche Werte:

   - **grouplist**
   - **publickey**


============
Item-Structs
============


Das Plugin stellt die folgenden Item-Structs zur Verfügung. Diese Informationen sind aus der `plugin.yaml` entnommen und möglicherweise nicht vollständig.


basic
=====

Default Webpush Template

.. treeview::
     - :dir:`folder` **basic** (`foo`, Default Webpush Template)
         - :dir:`folder` **config** (`foo`, Config items)
             - :dir:`file` **grouplist** (`list`, group list item)
             - :dir:`file` **publickey** (`str`, public key item)
         - :dir:`folder` **comunication** (`foo`, Communication items)
             - :dir:`file` **fromclient** (`str`, from client item)
