Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.10.0.3**
 - Minimum Python Version: **3.9**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **smartmeter** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


autoreconnect
=============




 - Datentyp: **bool**
 - Standardwert: **True**


baudrate
========




 - Datentyp: **int**
 - Standardwert: **9600**

 - Minimalwert: **50**

baudrate_min
============




 - Datentyp: **int**
 - Standardwert: **300**

 - Minimalwert: **50**

buffersize
==========




 - Datentyp: **int**
 - Standardwert: **1024**


crontab
=======




 - Datentyp: **str**


cycle
=====




 - Datentyp: **int**
 - Standardwert: **60**

 - Minimalwert: **0**

date_offset
===========




 - Datentyp: **int**
 - Standardwert: **0**


device_address
==============




 - Datentyp: **str**


device_type
===========




 - Datentyp: **str**

 - Mögliche Werte:

   - 


host
====




 - Datentyp: **str**


normalize
=========




 - Datentyp: **bool**
 - Standardwert: **True**


only_listen
===========




 - Datentyp: **bool**
 - Standardwert: **False**


poll
====




 - Datentyp: **bool**
 - Standardwert: **True**


port
====




 - Datentyp: **int**


protocol
========




 - Datentyp: **str**

 - Mögliche Werte:

   - **DLMS**
   - **SML**
   - **dlms**
   - **sml**
   - 


querycode
=========




 - Datentyp: **str**
 - Standardwert: **?**


serialport
==========




 - Datentyp: **str**


time_filter
===========




 - Datentyp: **int**
 - Standardwert: **0**


timeout
=======




 - Datentyp: **int**
 - Standardwert: **2**


use_checksum
============




 - Datentyp: **bool**
 - Standardwert: **True**

Item Attribute
==============

 - Minimalwert: **0**
 - Maximalwert: **10**

   - **unit**
   - **unitCode**

   - **obis**
   - **valTime**
   - **actTime**
   - **scaler**
   - **signature**
   - **status**
   - **statRun**
   - **statFraudMagnet**
   - **statFraudCover**
   - **statEnergyTotal**
   - **statEnergyL1**
   - **statEnergyL2**
   - **statEnergyL3**
   - **statRotaryField**
   - **statBackstop**
   - **statCalFault**
   - **statVoltageL1**
   - **statVoltageL2**
   - **statVoltageL3**


obis_readout
============




 - Datentyp: **str**


obis_vtype
