Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


LU_ID
=====




 - Datentyp: **int**
 - Standardwert: **130**


PANEL_ID
========




 - Datentyp: **int**
 - Standardwert: **120**


WP_ID
=====




 - Datentyp: **int**
 - Standardwert: **140**


busmonitor
==========




 - Datentyp: **bool**
 - Standardwert: **False**


device
======




 - Datentyp: **int**
 - Standardwert: **0**


retrylimit
==========




 - Datentyp: **int**
 - Standardwert: **100**


tty
===




 - Datentyp: **str**
