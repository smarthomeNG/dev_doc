Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.6**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **uzsu** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


backintime
==========




 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**

ignore_once_entries
===================




 - Datentyp: **bool**
 - Standardwert: **False**


interpolation_interval
======================




 - Datentyp: **int**
 - Standardwert: **5**

 - Minimalwert: **0**

interpolation_precision
=======================




 - Datentyp: **int**
 - Standardwert: **2**

 - Minimalwert: **0**
 - Maximalwert: **4**

interpolation_type
==================




 - Datentyp: **str**
 - Standardwert: **none**

 - Mögliche Werte:

   - **none**
   - **cubic**
   - **linear**


remove_duplicates
=================




 - Datentyp: **bool**
 - Standardwert: **True**


suncalculation_cron
===================




 - Datentyp: **str**
 - Standardwert: **0 0 * ***


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


uzsu_item
=========




 - Datentyp: **str**


============
Item-Structs
============


Das Plugin stellt die folgenden Item-Structs zur Verfügung. Diese Informationen sind aus der `plugin.yaml` entnommen und möglicherweise nicht vollständig.


child
=====

Vorlage-Struktur für Zeitschaltuhren

.. treeview::
     - :dir:`folder` **child** (`foo`, Vorlage-Struktur für Zeitschaltuhren)
         - :dir:`folder` **uzsu** (`dict`, ---)
             - :dir:`file` **last** (`foo`, The last set value if UZSU is active)
             - :dir:`folder` **active** (`bool`, Use this item to easily turn on or off your UZSU)
                 - :dir:`file` **status** (`bool`, ---)
             - :dir:`folder` **next** (`dict`, The next value and time)
                 - :dir:`file` **value** (`str`, The next value)
                 - :dir:`file` **time** (`str`, The next time)
