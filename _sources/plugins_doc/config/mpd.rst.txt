Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.8.2a**
 - Minimum Python Version: **3.6**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **mpd** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


cycle
=====




 - Datentyp: **int**
 - Standardwert: **2**


host
====




 - Datentyp: **ip**


port
====




 - Datentyp: **int**
 - Standardwert: **6600**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


mpd_command
===========




 - Datentyp: **str**

 - Mögliche Werte:

   - **playpause**
   - **mute**
   - **volume**
   - **repeat**
   - **random**
   - **single**
   - **consume**
   - **next**
   - **pause**
   - **play**
   - **playid**
   - **previous**
   - **seek**
   - **seekid**
   - **seekcur**
   - **stop**
   - **crossfade**
   - **mixrampdb**
   - **mixrampdelay**
   - **setvol**
   - **replay_gain_mode**


mpd_database
============




 - Datentyp: **str**

 - Mögliche Werte:

   - **update**
   - **rescan**


mpd_localplaylist
=================




 - Datentyp: **str**


mpd_rawcommand
==============




 - Datentyp: **str**


mpd_songinfo
============




 - Datentyp: **str**

 - Mögliche Werte:

   - **Last-Modified**
   - **Artist**
   - **Album**
   - **Title**
   - **Track**
   - **Time**
   - **Pos**
   - **Id**


mpd_statistic
=============




 - Datentyp: **str**

 - Mögliche Werte:

   - **artists**
   - **albums**
   - **songs**
   - **uptime**
   - **db_playtime**
   - **db_update**
   - **playtime**

 - Datentyp: **str**

   - **repeat**

   - **playlist**

   - **bitrate**
   - **audio**
   - **nextsong**
   - **nextsongid**
   - **duration**
   - **xfade**
   - **mixrampdelay**
   - **updating_db**
   - **error**


mpd_url
=======




 - Datentyp: **str**
