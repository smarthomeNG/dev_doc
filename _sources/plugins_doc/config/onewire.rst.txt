Anforderungen
=============

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **onewire** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


button_wait
===========




 - Datentyp: **num**
 - Standardwert: **0.5**


cycle
=====




 - Datentyp: **int**
 - Standardwert: **300**


cycle_discovery
===============




 - Datentyp: **int**
 - Standardwert: **600**


host
====




 - Datentyp: **ip**
 - Standardwert: **127.0.0.1**


io_wait
=======




 - Datentyp: **num**
 - Standardwert: **5**


log_counter_cycle_discovery_time
================================




 - Datentyp: **int**
 - Standardwert: **5**


log_counter_cycle_time
======================




 - Datentyp: **int**
 - Standardwert: **5**


log_counter_io_loop_time
========================




 - Datentyp: **num**
 - Standardwert: **10**


parasitic_power_wait
====================




 - Datentyp: **num**
 - Standardwert: **0.5**

 - Minimalwert: **0.1**
 - Maximalwert: **1.5**

port
====




 - Datentyp: **int**
 - Standardwert: **4304**


warn_after
==========




 - Datentyp: **int**
 - Standardwert: **10**
