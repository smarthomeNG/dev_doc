Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.4**
 - Maximum Python Version: **3.13**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **gpio** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


bouncetime
==========




 - Datentyp: **int**
 - Standardwert: **300**


chip
====




 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**
 - Maximalwert: **4**

mode
====




 - Datentyp: **str**
 - Standardwert: **BOARD**

 - Mögliche Werte:

   - **board**
   - **bcm**
   - **BOARD**
   - **BCM**


pullupdown
==========




 - Datentyp: **str**
 - Standardwert: **up**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


gpio_in
=======




 - Datentyp: **int**


gpio_init
=========




 - Datentyp: **bool**


gpio_invert
===========




 - Datentyp: **bool**


gpio_out
========




 - Datentyp: **int**


gpio_pud
========




 - Datentyp: **str**

 - Mögliche Werte:

   - **up**
   - **UP**
   - **down**
   - **DOWN**
   - **none**
   - **NONE**
