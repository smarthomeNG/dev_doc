Anforderungen

Konfiguration

Im folgenden ist beschrieben, wie das Plugin **tasmota** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


full_topic
==========




 - Datentyp: **str**
 - Standardwert: **%prefix%/%topic%/**


telemetry_period
================




 - Datentyp: **int**
 - Standardwert: **300**

 - Minimalwert: **10**
 - Maximalwert: **3600**

==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


tasmota_admin
=============




 - Datentyp: **str**
 - Standardwert: **delete_retained_messages**

 - Mögliche Werte:

   - **delete_retained_messages**


tasmota_attr
============




 - Datentyp: **str**
 - Standardwert: **relay**


tasmota_button
==============




 - Datentyp: **int**
 - Standardwert: **1**

 - Minimalwert: **1**
 - Maximalwert: **4**

tasmota_relay
=============




 - Datentyp: **int**
 - Standardwert: **1**

 - Minimalwert: **1**
 - Maximalwert: **4**

tasmota_rf_details
==================




 - Datentyp: **str**


tasmota_sml_attr
================




 - Datentyp: **str**


tasmota_sml_device
==================




 - Datentyp: **str**


tasmota_topic
=============




 - Datentyp: **str**


tasmota_zb_attr
===============




 - Datentyp: **str**


tasmota_zb_cluster
==================




 - Datentyp: **bool**
 - Standardwert: **False**


tasmota_zb_device
=================




 - Datentyp: **str**


tasmota_zb_group
================




 - Datentyp: **num**
