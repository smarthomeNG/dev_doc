Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.8**
 - Minimum Python Version: **3.6**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **dlms** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


baudrate
========




 - Datentyp: **int**
 - Standardwert: **300**

 - Minimalwert: **50**

baudrate_fix
============




 - Datentyp: **bool**
 - Standardwert: **False**


device_address
==============




 - Datentyp: **str**


no_waiting
==========




 - Datentyp: **bool**
 - Standardwert: **False**


only_listen
===========




 - Datentyp: **bool**
 - Standardwert: **False**


querycode
=========




 - Datentyp: **str**
 - Standardwert: **?**


reset_baudrate
==============




 - Datentyp: **bool**
 - Standardwert: **True**


serialport
==========




 - Datentyp: **str**


timeout
=======




 - Datentyp: **int**
 - Standardwert: **2**


update_crontab
==============




 - Datentyp: **str**


update_cycle
============




 - Datentyp: **int**
 - Standardwert: **60**

 - Minimalwert: **0**

update_cycle_start_offset
=========================




 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**

use_checksum
============




 - Datentyp: **bool**
 - Standardwert: **True**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


dlms_obis_code
==============




 - Datentyp: **list(4,str,int,str,str)**


dlms_obis_readout
=================




 - Datentyp: **str**
