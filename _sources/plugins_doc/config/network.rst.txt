Konfiguration

Im folgenden ist beschrieben, wie das Plugin **network** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


http
====




 - Datentyp: **str**
 - Standardwert: **no**


http_acl
========




 - Datentyp: **list**
 - Standardwert: *****


ip
==




 - Datentyp: **ip**
 - Standardwert: **0.0.0.0**


port
====




 - Datentyp: **int**
 - Standardwert: **2727**

 - Minimalwert: **1**
 - Maximalwert: **65535**

tcp
===




 - Datentyp: **bool**
 - Standardwert: **False**


tcp_acl
=======




 - Datentyp: **list**
 - Standardwert: *****


udp
===




 - Datentyp: **bool**
 - Standardwert: **False**


udp_acl
=======




 - Datentyp: **list**
 - Standardwert: *****

 - Datentyp: **list**


nw_http_listen
==============




 - Datentyp: **str**


nw_tcp_listen
=============




 - Datentyp: **str**


nw_udp_listen

nw_udp_send

 - Datentyp: **str**
