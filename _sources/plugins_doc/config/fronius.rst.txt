Beschreibung
============

Plugin Auslesen eines Fronius Wechserichters


Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.10**
 - Minimum Python Version: **3.11**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **fronius** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


ip_address
==========


IP Adresse des Wechselrichters

 - Datentyp: **str**
 - Standardwert: **192.168.1.1**


poll_cycle
==========


Zyklus, in dem die Informationen abgefragt werden sollen.

 - Datentyp: **int**
 - Standardwert: **10**


timeout
=======


Timeout Wert für http Anfragen an den Inverter

 - Datentyp: **int**
 - Standardwert: **10**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


fronius_data
============


Datenfeld des Inverters

 - Datentyp: **str**

 - Mögliche Werte:

   - **soc**
   - **p_pv**
   - **p_grid**
   - **p_accu**
   - **p_load**
   - **p_pv_day**
   - **p_pv_day_database**
