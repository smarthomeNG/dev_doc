=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


address
=======




 - Datentyp: **ip**


port
====




 - Datentyp: **int**
 - Standardwert: **8080**

 - Minimalwert: **0**

setname
=======




 - Datentyp: **str**


setpath
=======




 - Datentyp: **str**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


eta_pu_error
============




 - Datentyp: **str**

 - Mögliche Werte:

   - 
   - **yes**
   - **no**


eta_pu_type
===========




 - Datentyp: **str**

 - Mögliche Werte:

   - **strValue**
   - **unit**
   - **decPlaces**
   - **scaleFactor**
   - **advTextOffset**
   - **calc**


eta_pu_uri
==========




 - Datentyp: **str**
