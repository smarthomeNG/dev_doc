Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.9**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **enocean** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


log_unknown_messages
====================




 - Datentyp: **bool**
 - Standardwert: **False**


retry
=====




 - Datentyp: **int**
 - Standardwert: **10**


retry_cycle
===========




 - Datentyp: **int**
 - Standardwert: **5**


serialport
==========




 - Datentyp: **str**
 - Standardwert: **/dev/ttyAMA0**


tx_id
=====




 - Datentyp: **str**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


block_dim_value
===============




 - Datentyp: **str**
 - Standardwert: **False**


block_switch
============




 - Datentyp: **str**
 - Standardwert: **False**


color
=====




 - Datentyp: **str**
 - Standardwert: **red**


dim_speed
=========




 - Datentyp: **str**
 - Standardwert: **50**


enocean_device
==============




 - Datentyp: **str**

 - Mögliche Werte:

   - **FSUD-230V**
   - **FUD61NPN-230V**
   - **FSVA-230V**
   - **FSM60B**
   - **FLD61**
   - **FUD70S-230V**
   - **FBH63TF**
   - **NodOn-STP-2-1-03**
   - **SecuSignal**
   - **FB55EB-wg**
   - **FBH63AP**


enocean_rocker_action
=====================




 - Datentyp: **str**

 - Mögliche Werte:

   - **UNSET**
   - **TOGGLE**
   - **SET**


enocean_rocker_sequence
=======================




 - Datentyp: **str**


enocean_rtime
=============




 - Datentyp: **str**
 - Standardwert: **60**


enocean_rx_eep
==============




 - Datentyp: **str**


enocean_rx_id
=============




 - Datentyp: **str**


enocean_rx_key
==============




 - Datentyp: **str**
 - Standardwert: **A**


enocean_tx_eep
==============




 - Datentyp: **str**


enocean_tx_id_offset
====================




 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**
 - Maximalwert: **127**

ref_level
=========




 - Datentyp: **str**
 - Standardwert: **80**
