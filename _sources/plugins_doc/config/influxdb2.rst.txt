Anforderungen
=============

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **influxdb2** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


api_token
=========




 - Datentyp: **str**


bucket
======




 - Datentyp: **str**
 - Standardwert: **shng**


host
====




 - Datentyp: **str**
 - Standardwert: **127.0.0.1**


http_port
=========




 - Datentyp: **int**
 - Standardwert: **8086**

 - Minimalwert: **0**
 - Maximalwert: **65535**

org
===




 - Datentyp: **str**
 - Standardwert: **smarthomeng**


recognize_database
==================




 - Datentyp: **bool**


str_value_field
===============




 - Datentyp: **str**
 - Standardwert: **str_value**


tags
====




 - Datentyp: **dict**


value_field
===========




 - Datentyp: **str**
 - Standardwert: **value**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


database
========




 - Datentyp: **str**


influxdb2
=========




 - Datentyp: **str**


influxdb2_bucket
================




 - Datentyp: **str**


influxdb2_name
==============




 - Datentyp: **str**


influxdb2_tags
==============




 - Datentyp: **str**
