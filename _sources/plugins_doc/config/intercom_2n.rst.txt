Konfiguration

Im folgenden ist beschrieben, wie das Plugin **intercom_2n** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


auth_type
=========


Zu verwendender auth_type (0: no authentication, 1: Basic Authentication, 2: Digest Authentication)

 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**
 - Maximalwert: **2**

intercom_ip
===========


Intercom IP Adresse

 - Datentyp: **ip**


password
========


Passwort, falls auth_type > 0

 - Datentyp: **str**
 - Standardwert: **None***


ssl
===


ssl Verschlüsselung verwenden

 - Datentyp: **bool**
 - Standardwert: **False**


username
========


Benutzername, falls auth_type > 0

 - Datentyp: **str**
 - Standardwert: **None***


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


command_2n
==========


Name des Befehls, am Item, dessen Wert nach Ausführung das Ergebnis des Befehls enthält, oder "execute" an einem Kind-Item, um den Befehl auszulösen. Details siehe Anwenderdokumentation.

 - Datentyp: **str**

 - Mögliche Werte:

   - **audio_test**
   - **call_answer**
   - **call_dial**
   - **call_hangup**
   - **call_status**
   - **camera_caps**
   - **camera_snapshot**
   - **config_get**
   - **config_upload**
   - **display_caps**
   - **display_delete_image**
   - **display_upload_image**
   - **email_send**
   - **execute**
   - **factory_reset**
   - **firmware_apply**
   - **firmware_upload**
   - **io_caps**
   - **io_control**
   - **io_status**
   - **log_caps**
   - **pcap**
   - **pcap_restart**
   - **pcap_stop**
   - **phone_status**
   - **switch_caps**
   - **switch_control**
   - **switch_status**
   - **system_info**
   - **system_restart**
   - **system_status**


event_2n
========


Name des Ereignistyps, am Item, das als Container für das Ereignis dient. Details siehe Anwenderdokumentation.

 - Datentyp: **str**

 - Mögliche Werte:

   - **AudioLoopTest**
   - **CallStateChanged**
   - **CardEntered**
   - **CardHeld**
   - **CodeEntered**
   - **DeviceState**
   - **DoorOpenTooLong**
   - **InputChanged**
   - **KeyPressed**
   - **KeyReleased**
   - **LoginBlocked**
   - **MotionDetected**
   - **NoiseDetected**
   - **OutputChanged**
   - **PairingStateChanged**
   - **RegistrationStateChanged**
   - **SwitchStateChanged**
   - **TamperSwitchActivated**
   - **UnauthorizedDoorOpen**
   - **UserAuthenticated**


event_data_2n
=============


Name des Datenfelds innerhalb der Ereignis-Nutzdaten, an einem Kind-Item von event_2n. Der Wert dieses Datenfelds wird bei Eintreten des Ereignisses in das Item geschrieben. Details siehe Anwenderdokumentation.

 - Datentyp: **str**
