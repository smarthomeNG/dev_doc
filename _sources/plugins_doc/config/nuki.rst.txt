Anforderungen

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **nuki** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


bridge_api_token
================




 - Datentyp: **str**


bridge_ip
=========




 - Datentyp: **ip**


bridge_port
===========




 - Datentyp: **int**


mode
====




 - Datentyp: **num**
 - Standardwert: **2**

 - Mögliche Werte:

   - **1**
   - **2**
   - **3**


no_wait
=======




 - Datentyp: **bool**
 - Standardwert: **True**


protocol
========




 - Datentyp: **str**
 - Standardwert: **http**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


nuki_id
=======




 - Datentyp: **str**


nuki_trigger
============




 - Datentyp: **str**

 - Mögliche Werte:

   - **state**
   - **doorstate**
   - **battery**
   - **action**
   - **mqtt_state**
   - **mqtt_battery_critical**
   - **mqtt_battery_charge_state**
   - **mqtt_mode**
   - **mqtt_action**
