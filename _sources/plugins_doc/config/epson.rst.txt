Im folgenden sind etwaige Anforderungen und unterstützte Hardware beschrieben. Danach folgt die               Beschreibung, wie das Plugin **epson** konfiguriert wird. Außerdem ist im folgenden               beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann. [#f1]_ 

Es handelt sich bei diesem Plugin um ein **interface Plugin**.

**ACHTUNG**: Dieses Plugin ist als develop gekennzeichnet. Es kann daher sein, dass es                  noch nicht sämtliche Funktionen unterstützt oder noch fehlerhaft ist.



Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.9.5**
 - Minimum Python Version: **3.7**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **epson** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


autoconnect
===========




 - Datentyp: **bool**


autoreconnect
=============




 - Datentyp: **bool**
 - Standardwert: **True**


baudrate
========




 - Datentyp: **num**
 - Standardwert: **9600**


binary
======




 - Datentyp: **bool**
 - Standardwert: **False**


bytesize
========




 - Datentyp: **num**
 - Standardwert: **8**


command_class
=============




 - Datentyp: **str**
 - Standardwert: **SDPCommandParseStr**

 - Mögliche Werte:

   - **SDPCommand**
   - **SDPCommandParseStr**


conn_type
=========




 - Datentyp: **str**
 - Standardwert: **serial_async**

 - Mögliche Werte:

   - 
   - **net_tcp_client**
   - **serial_async**


connect_cycle
=============




 - Datentyp: **num**
 - Standardwert: **3**


connect_retries
===============




 - Datentyp: **num**
 - Standardwert: **5**


host
====




 - Datentyp: **str**


model
=====




 - Datentyp: **str**

 - Mögliche Werte:

   - 
   - **TW-5000**


parity
======




 - Datentyp: **str**
 - Standardwert: **N**

 - Mögliche Werte:

   - **N**
   - **E**
   - **O**
   - **M**
   - **S**


port
====




 - Datentyp: **int**
 - Standardwert: **23**


retry_cycle
===========




 - Datentyp: **num**
 - Standardwert: **30**


retry_suspend
=============




 - Datentyp: **num**
 - Standardwert: **3**


serialport
==========




 - Datentyp: **str**


stopbits
========




 - Datentyp: **num**
 - Standardwert: **1**


suspend_item
============




 - Datentyp: **str**


terminator
==========




 - Datentyp: **str**
 - Standardwert: **\r**


timeout
=======




 - Datentyp: **num**
 - Standardwert: **3**

 - Datentyp: **str**


epson_read
==========




 - Datentyp: **bool**


epson_read_cycle
================




 - Datentyp: **num**


epson_read_group
================




 - Datentyp: **list(str)**


epson_read_group_trigger
========================




 - Datentyp: **str**


epson_read_initial
==================




 - Datentyp: **bool**


epson_write
===========




 - Datentyp: **bool**
