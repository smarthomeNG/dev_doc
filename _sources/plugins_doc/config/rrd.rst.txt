Beschreibung
============




Anforderungen
=============




 - Minimum SmartHomeNG Version: **1.10**
 - Minimum Python Version: **3.8**

Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **rrd** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


rrd_dir
=======




 - Datentyp: **str**


step
====




 - Datentyp: **int**
 - Standardwert: **300**


==============
Item Attribute
==============


Das Plugin unterstützt folgende Item Attribute, die in den Dateien im Verzeichnis  ``../items`` verwendet werden:


rrd
===




 - Datentyp: **str**

 - Mögliche Werte:

   - 
   - **yes**
   - **init**


rrd_ds_name
===========




 - Datentyp: **str**


rrd_max
=======




 - Datentyp: **bool**
 - Standardwert: **False**


rrd_min
=======




 - Datentyp: **bool**
 - Standardwert: **False**


rrd_no_series
=============




 - Datentyp: **bool**
 - Standardwert: **False**


rrd_step
========




 - Datentyp: **int**


rrd_type
========




 - Datentyp: **str**

 - Mögliche Werte:

   - 
   - **gauge**
   - **counter**
