Konfiguration
=============


Im folgenden ist beschrieben, wie das Plugin **artnet** konfiguriert wird. Außerdem ist im folgenden beschrieben, wie das Plugin in den Item Definitionen genutzt werden kann.


=========
Parameter
=========


Das Plugin verfügt über folgende Parameter, die in der Datei ``../etc/plugin.yaml`` konfiguriert werden:


artnet_net
==========




 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**
 - Maximalwert: **127**

artnet_subnet
=============




 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**
 - Maximalwert: **15**

artnet_universe
===============




 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**
 - Maximalwert: **15**

ip
==




 - Datentyp: **ip**
 - Standardwert: **127.0.0.1**


min_channels
============




 - Datentyp: **int**
 - Standardwert: **1**

 - Minimalwert: **1**
 - Maximalwert: **512**

port
====




 - Datentyp: **int**
 - Standardwert: **6454**


update_cycle
============




 - Datentyp: **int**
 - Standardwert: **0**

 - Minimalwert: **0**

artnet_address

 - Datentyp: **int**

 - Minimalwert: **1**
 - Maximalwert: **512**
